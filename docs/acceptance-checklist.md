# 《来250杯！》原型验收清单

给验收方（Codex、其他 AI agent 或人工）使用。每一条都写了**怎么验**和**通过标准**。
规则的唯一来源是 `docs/game-design.md` 和 `CLAUDE.md` 的“Design rules”。验收方只负责报告，不要顺手改代码；发现问题写进报告。

所有命令都在 `game/` 目录下执行。

---

## A. 自动化测试（必须全部通过）

| # | 怎么验 | 通过标准 |
|---|---|---|
| A1 | `node --test test/*.test.mjs` | `fail 0`。当前共 44 个测试 |
| A2 | `node tools/check-content.mjs` | 最后一行 `17/17 checks passed`，退出码 0（含 V1–V2 语音包覆盖检查） |
| A3 | 先起服务 `python3 -m http.server 8765 &`，再跑 `node tools/play-integrate.mjs` | 输出的 JSON 里 `"errors": []` 且 `"overflow": false` |
| A4 | 服务保持运行，跑 `node tools/qa.mjs`（约几分钟） | 最后一行 `21/21 passed`，退出码 0 |

注意：
- Node 22 下 `node --test test` 传目录会报错，必须用 `test/*.test.mjs`。
- Playwright 用全局安装的版本和预装的 Chromium（`/opt/pw-browsers`），**不要**运行 `playwright install`。
- 跑完记得关掉服务：`pkill -f "http.server 8765"`。

## C. 设计红线

自动部分（A2 脚本）：

| # | 检查项 |
|---|---|
| C1 | 游戏文本里没有外送员相关角色或词汇 |
| C2 | 没有奇幻元素（羊驼、外星人、太空、魔法等） |
| C3 | 明骂（X你妈）只占约一成，当重拳用（8 到 14 位顾客） |
| C4 | 250 是招牌数字：有 250 杯大户，且至少 5 句“250 暗骂” |
| C5 | 招牌台词存在：“黄金比例最好喝”“两个月”“下一位” |
| C6 | 引擎默认 `auraWrong` 为 0，`main.js` 没有把它覆盖成扣分 |
| C7 | 按错键不扣气势，排队照样增长（唯一的失败是太慢） |

人工部分（逐条读 `game/src/content.zh.js` 和 `content.en.js` 判断，在报告里列出可疑的编号）：

| # | 检查项 | 通过标准 |
|---|---|---|
| C8 | 不拿外貌、性别、种族、出身、政治、宗教开玩笑 | 0 处 |
| C9 | 没有“不能骂的人”，也没有店员对某一类人特别温柔 | 0 处。“破功一秒马上凶回去”属于反差，可以 |
| C10 | 所有进店的人都能骂，没有“憋住不骂”的规则或关卡 | 0 处 |

## D. 游玩手感（浏览器验收）

用 Playwright 打开 `http://localhost:8765/?debug`，视口 390x844（手机）和 1280x800（桌面）。
加上 `?debug` 后可以用 `window.__250.game` 读取状态（`game.state`）、用 `game.tick(ms)` 快进时间。
键盘 J / K / L 等于“滚 / 闭嘴 / 收”，按住超过 300ms 或 800ms 是蓄力一段、两段。

| # | 操作 | 通过标准 |
|---|---|---|
| D1 | 打开页面 | 出现开始卡片，有“开店！”按钮；页面没有横向滚动条；console 无报错 |
| D2 | 点“开店！” | 1 秒内出现第一位顾客：半个头、头顶标记、名字、对话气泡、耐心条 |
| D3 | 按当前顾客的正确键（`game.state.current.customer.key`） | 字幕出现店员台词（括号内是小字舞台指示）；画面震动；顾客飞向门口；排队数字增加 |
| D4 | 按错键 | 仍然骂出去（字幕出现台词），排队 +1，**气势不减少** |
| D5 | 什么都不按，等耐心条走完 | 店员变僵硬笑脸、画面变粉、出现服务腔台词和嘘声文字；气势下降 |
| D6 | 连续按对直到火气满 | 进入爆气：全屏变红、店员站上柜台、字幕连发；8 秒后恢复 |
| D7 | 排队到 10、100、1000 | 依次出现里程碑卡片（门口、骑楼、捷运站） |
| D8 | 点到 250 杯大户（编号 47）并按“收” | 出现巨大金色“250”特效 |
| D9 | 让一局结束（时间到或气势归零） | 出现战报卡：开骂次数、排队人数、最高连击、分数、“最狠一句”；没有 undefined 或 NaN；“再骂一天”可以重开 |
| D10 | 点右上角“中/EN” | 开始卡、游戏中、战报卡的所有文字都变成英文，没有残留中文（菜单牌除外，若有则记录） |
| D11 | 点“消音” | 状态切换并在刷新后保留（存在 localStorage） |
| D12 | 360x640 小屏 | 按钮、字幕、战报都不被截断，不溢出 |

## E. 语音（需要有声音的真实设备，自动化环境只能验调用和网络请求）

语音来自 `game/voice/` 的 AI 语音包（Kokoro-82M，Apache-2.0，见 `game/tools/voice/README.md`）；没有对应片段的台词才退回浏览器语音合成。

| # | 操作 | 通过标准 |
|---|---|---|
| E1 | 打开页面 | Network 面板里请求了 `voice/manifest.json`；点“开店！”后开始下载当前语言的 `voice/zh-*.mp3`（或 `en-*.mp3`） |
| E2 | 顾客出现 | 用顾客的 AI 声音朗读顾客台词；不同顾客声音不同 |
| E3 | 按键骂人 | 用店员的 AI 声音朗读台词，括号里的舞台指示**不朗读**；新台词会打断旧台词 |
| E4 | 超时 | 店员用服务腔朗读，同时有两句群众嘘声（不同声音）叠在嘘声音效上 |
| E5 | 排队里程碑 | 播报员声音念出里程碑文字，不打断店员 |
| E6 | 打开消音后骂明骂台词（例如编号 11 “调你妈”） | “你妈”被 1kHz 的“哔”声替换 |
| E7 | 切换到 EN | 所有语音换成英文声音 |
| E8 | 拍柜台、顾客飞走、嘘声、欢呼、爆气 | 都有音效；除 `voice/` 下的语音包外，没有加载任何其他音频文件 |

自动化环境里：`?debug` 下 `window.__250.audio.hasVoicePack` 应为 `true`，`window.__250.audio.hasClip('调你妈！黄金比例最好喝！')` 应为 `true`。

## F. 已知问题（不算验收失败，但要在报告里确认是否仍存在）

1. 游戏内的中文台词是 v2；`docs/lines-zh.md`（v3）和配音稿还没有同步进 `content.zh.js`。
2. 英文 250 梗不一致：游戏里用 “CODE 250”，`docs/voice/voice-script-en.md` 用 “quarter-wit” 口误方案，待制作人决定。
3. 蓄力（按住 800ms 以上）和“完美”（600ms 内反应）互斥；按键在松手时才结算。
4. 爆气开场、PERFECT、250 金字、里程碑卡片可能同时出现，小屏上会糊在一起。
5. 新手什么都不按约 10 秒就结束，缺少新手保护。
6. 语音是 AI 生成（Kokoro），只能调语速，没有情绪控制；“秒回正经”的切换和中二腔调效果有限。正式版要换真人配音。
7. 内容是简体中文；台湾上架需要繁体中文。
