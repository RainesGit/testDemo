# 《来250杯！》原型验收清单

给验收方（Codex、其他 AI agent 或人工）使用。每一条都写了**怎么验**和**通过标准**。
规则的唯一来源是 `docs/game-design.md`、`docs/first-minute-spec.md`（第一分钟改版，冲突时以它为准）和 `CLAUDE.md` 的“Design rules”。验收方只负责报告，不要顺手改代码；发现问题写进报告。

所有命令都在 `game/` 目录下执行。

---

注意：
- Node 22 下 `node --test test` 传目录会报错，必须用 `test/*.test.mjs`。
- 浏览器脚本通过 `tools/pw.mjs` 查找 Playwright：本地安装、全局 npm、`/opt/node22`。云端容器已预装 Chromium（`/opt/pw-browsers`），**不要**运行 `playwright install`；本机（如 macOS）没有时执行 `npm i --prefix tools playwright && npx --prefix tools playwright install chromium`。
- 浏览器脚本是真实时间运行，不要同时跑两个，否则计时类检查（A1、A3、A7）可能受干扰。
- 截图在 `tools/shots/`：`integrate-*`、`qa-*`、`opening-<视口>-<拍>.png`。
- 跑完记得关掉服务：`pkill -f "m http.server 876[5]"`（方括号写法避免误杀执行这条命令的 shell 自己）。

## D. 游玩手感（浏览器验收）

用 Playwright 打开 `http://localhost:8765/?debug`，视口 390x844（手机）和 360x640（小屏）。
加上 `?debug` 后可以用 `window.__250.game` 读取状态（`game.state`）、`window.__250.opening` 读取剧本（`beat`、`waiting`）。
`?skipOpening=1` 跳过剧本直接进第 1 天自由营业，`?day=N` 从第 N 天开始。
键盘 J / K / L 等于“滚 / 闭嘴 / 收”。按下即结算，继续按住到 300ms / 800ms 是同一次回答的蓄力一段、两段。

## E. 语音（需要有声音的真实设备，自动化环境只能验调用和网络请求）

语音来自 `game/voice/` 的 AI 语音包（Kokoro-82M，Apache-2.0，见 `game/tools/voice/README.md`）；没有对应片段的台词才退回浏览器语音合成。

| # | 操作 | 通过标准 |
|---|---|---|
| E1 | 打开页面 | Network 面板里请求了 `voice/manifest.json`；点“开店！”后开始下载当前语言的 `voice/zh-*.mp3`（或 `en-*.mp3`） |
| E2 | 顾客出现 | 用顾客的 AI 声音朗读顾客台词；不同顾客声音不同 |
| E3 | 按键骂人 | 用店员的 AI 声音朗读台词，括号里的舞台指示**不朗读**；新台词会打断旧台词 |
| E4 | 超时 | 店员用服务腔朗读，同时有两句群众嘘声（不同声音）叠在嘘声音效上 |
| E5 | 排队里程碑 | 播报员声音念出里程碑文字，不打断店员 |
| E6 | 打开消音后骂明骂台词（例如编号 9 “改你妈！”；英文 #67 “Split my ASS!”） | “你妈”/“your MOM”/“ASS”被 1kHz 的“哔”声替换 |
| E7 | 切换到 EN | 所有语音换成英文声音 |
| E8 | 拍柜台、顾客飞走、嘘声、欢呼、爆气 | 都有音效；除 `voice/` 下的语音包外，没有加载任何其他音频文件 |
| E9 | 剧本里的切点台词（如“还在想？\|滚！”） | 铺垫段和爆点段之间有一段静音，爆点时背景声被压下；语音包重建后人工听一遍“250”是否读成“二百五十”（规格 K1） |
