# Codex 任务：让配音不再僵硬

> 制作人（2026-10-31）："说文字的声音太僵硬了""还是太僵硬"，"codex 自己想办法就可以，不用限制"。

## 目标

重做游戏的全部配音：中文（台湾华语）和英文，店员、客人、播报员。要听起来像真人在演，不要像机器在念：

- **店员的核心笑点是三拍反差：** 礼貌服务 → 突然爆骂 → 秒回专业。骂人那一下要有爆发力，礼貌话要甜到假。
- **快速连骂时也要听得清楚。**

**用什么工具、模型、服务、方法，全部由你决定，不设限制。**

## 现况（供参考）

- 现在的配音是 Kokoro（离线 AI），只能调语速、念得很平。生成脚本是 `game/tools/voice/build_voice.py`，说明在 `game/tools/voice/README.md`。
- 游戏在播放时为了补救做了一些处理（`game/src/audio.js` 的 `VOICE_FX`、`CONTOURS`）。配音包的 manifest 里写 `expressive: true` 时，会自动改用较轻的 `EXPRESSIVE_FX`。这些都可以按需要改或拿掉。
- 已经有一个现成的起点 `game/tools/voice/build_openai.py`：调用 OpenAI 语音接口，每句附上演出指令，用本地假接口测过。要不要用它，由你决定。
- **全部台词清单：** `node tools/voice/export-lines.mjs`（在 `game/` 下执行）。一共 1106 句，每句有角色、语气，以及是 `|` 前的铺垫半句还是后面的爆骂半句。
- **游戏读取的格式：** `game/voice/manifest.json` 加上 mp3 拼接档（见 `build_voice.py` 开头的说明）。用别的格式也可以，但要让游戏读得到。

## 2026-10-31 实施记录

- 分支：`claude/claude-md-docs-facm46`。
- 配音方案：本地 Qwen3-TTS 1.7B CustomVoice（固定 8-bit 权重版本），通过 MLX Audio 生成。
  中文店员使用 Uncle_Fu，英文店员使用 Ryan；客人和播报员使用内置声线。
  每句采用简短的角色与演出指令，分别处理服务腔、爆点、秒回专业、连骂等语气。
- 台词导出增加独立的 `beat`，保留先骂后解释的顺序及开场回归专业的表演意图。
  规范 TTS 输入中的省略号和长音标记，保留原文与游戏显示，不改写台词。
- `expressive: true` 选择较轻的播放处理：关闭合成音高轮廓和额外加速，降低失真与增益，保留冲击音和扩音器效果。
- 开场使用保留音高的 FFmpeg `atempo`（中文 1.12、英文 1.48），压紧演出节奏以满足 40 秒上限；
  超时服务腔及其接话单独标记 `reaction: timeout`（中文 1.85、英文 2.0），针对全超时路线的 70 秒上限校准。
  不截断台词、不缩短教学或高潮节拍。自由营业按旧包各角色的平均录音时长校准：
  中文客人 1.60 / 店员 1.72 / 群众与播报 1.51，英文客人 1.26 / 店员 1.64 / 群众 1.53 / 播报 1.56；
  共用开场 clip key 的台词优先沿用对应的开场或超时速度。所有处理都保留音高，参数随录音记录，试听与游戏包使用同一处理。
- 构建器支持逐句缓存、异常单句重试、失败汇总和整包发布；任一录音失败时保留旧包。
  固定模型版本并校验下载记录及哈希，`game/voice/synthesis.json` 保存逐句来源与生成参数。
- 试听入口：[`samples/index.html`](voice/samples/index.html)，中英文各 27 句，附合辑及消音样本。
  重建方式见 [`game/tools/voice/README.md`](../game/tools/voice/README.md)。
