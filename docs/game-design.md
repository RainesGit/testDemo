## 1. 一句话概念

**你是全台湾最凶的手摇饮店员，坐在超高柜台上俯视顾客，骂得越狠，门口排队的人越多。**

- 灵感：一支12年前的台湾短视频。三拍反差：**正经服务 → 突然爆骂 → 立刻恢复正经**。
- 250 = 二百五。店员一本正经地复述“250”，就是在暗骂。
- 每次交互、每段演出、每句台词，都要套用这三拍。

## 2. 设计支柱与红线

### 2.1 五根支柱

| 支柱 | 含义 | 设计检验问题 |
|---|---|---|
| **一秒判断** | 看头上的标记，一秒内出手 | 新玩家只看颜色和形状能不能分得清？ |
| **骂人永远不罚** | 唯一的失败是“太慢”；骂得不准只是加成变少 | 这个设计会不会让玩家“犹豫要不要骂”？会就删 |
| **三拍反差** | 正经 → 爆骂 → 正经 | 台词和演出有没有在最后恢复凶？ |
| **越骂人越多** | 被骂的人带朋友回来、网红开直播、被撞倒的人喊“我也要被骂” | 骂完以后，画面上有没有“人变多”的证据？ |
| **写实的荒谬** | 排队排到捷运站、101、新闻直升机，全部是真实场景 | 有没有出现奇幻、穿越、超自然？ |

### 2.2 红线（绝对不能出现）

| 红线 | 执行方式 |
|---|---|
| 外送员 | 游戏里没有这个角色，也没有外送相关的任何设定、道具或台词 |
| 不能骂的人 / 自己人优先 / 憋住不骂 / 骂错扣分 | 所有进店的人都可以骂。按错键只判“偏”，加成变少。文档和配置里也不保留“曾经有不能骂的人”的说明文字【改 R10】 |
| 奇幻元素 | 没有羊驼、外星人、太空、魔法，也没有时间旅行。“——两个月后——”只是剪辑式的时间跳转，年代梗只用“现在的顾客带着旧东西”【改 R9】 |
| 外貌、性别、种族、出身、政治、宗教 | 所有笑点只来自**点单行为**：杯数、犹豫、调甜调冰、问东问西、砍价、客诉、开会。绰号不用体型【改 R5、R6、R7、R8】 |
| 对某类人特别温柔 | 店员对谁都一样凶。“破功”一律由**行为或事件**触发，任何人都可能触发，而且一定在下一拍恢复凶【改 R1–R4】 |
| 灾害联动 | 不和真实台风、地震等警报联动【改 R13】 |
| 未成年人 | 学区店的顾客视觉一律是成人（大学生、重考生、家长、补习班老师），不出现高中制服，因此不需要任何豁免规则【改 R12】 |

## 3. 核心循环与操作

### 3.1 核心循环

```
顾客探头 → 看标记（≤1秒）→ 按 滚 / 闭嘴 / 收（可长按蓄力）
   → 骂人演出 + 台词 → 排队增加、火气上涨、连击累计
   → 火气满 → 爆气8秒连珠炮
   → 太慢 → 服务腔社死 → 下一位用3段复仇骂翻盘
   → 收摊拉铁门 → 战报卡 + 15秒短片 → 升级 / 图鉴 / 明天的小黑板谜语
```

核心循环里**不做饮料**。“收了不做，两个月后来拿”本身就是笑点。

### 3.2 屏幕布局（竖屏）

```
┌─────────────────────────────────┐
│ [排队地图条：门口▶骑楼▶捷运▶101▶直升机]  │ 顶部 6%
│ 排队 1,284   连击 x37   右上：新闻小窗  │
│                                       │
│      店员（坐在超高柜台上，俯视）         │ 上 35%
│ ═════════ 柜台边缘 ═════════            │
│   顾客半个头 + 头顶标记 + 话气泡         │ 中 30%（柜台前永远只有一位）
│   后面的队伍越来越小，一路排出门          │
│ 气势 ███████░░    火气 ████░░░░        │
│  ┌──────┐  ┌──────┐  ┌──────┐         │
│  │  滚  │  │ 闭嘴 │  │  收  │         │ 底部 22% 拇指区
│  └──────┘  └──────┘  └──────┘         │
└─────────────────────────────────┘
```

- 三个按钮各占宽度约30%，高110dp，间距12dp。支持左撇子镜像。
- **柜台前永远只有一位顾客**。团体顾客用“团体框”框起来，只显示一个标记，一键处理【改 C18】。
- 前主管来电的“滑动挂断”区域在店员头部旁，和三个按键分开。

### 3.3 头顶标记 → 最佳键（颜色 + 形状双编码）【改 C1、C3、M4】

| 标记 | 颜色 | 形状（色盲也能读） | 顾客 | 最佳键 |
|---|---|---|---|---|
| `……` 气泡 | 灰 | 向外的箭头 | 犹豫客（“嗯……”）、☎确认客 | **滚** |
| 小数字 `1` `3` `15` `25` `50` | 灰 | 向外的箭头 | 小单客 | **滚** |
| `249` | **金色数字 + 一道灰色裂痕** | 向外的箭头 | 差一杯客（陷阱） | **滚** |
| 大数字 `100` `250` `251` `520` | 金 | 号码牌 | 大单客 | **收** |
| `调` `？` `试` `票` `卡` | 红 | 打叉的嘴 | 奥客：调甜调冰、问东问西、要试喝试吃、载具/统编、客诉卡 | **闭嘴** |
| 金色数字 + 红色 `调`（双标记） | 金+红 | 号码牌 + 打叉的嘴 | 原片顾客：大单还要调 | **收 → 闭嘴**（两步） |
| 📱 角标 | 叠加 | 手机镜头 | 网红，叠加在任何标记上 | 照底下的标记判断 |
| ↺ 角标 | 叠加 | 回转箭头 | 回头客 | 照底下的标记判断 |

- 新手只看颜色：**灰＝滚，红＝闭嘴，金＝收**。熟手再看249的裂痕。
- 标记是UI层，**永远不缩小、不被遮挡、不变灰**。天气、雨伞、柜台加高只影响顾客身体【改 C17、3.2删除表】。
- 设置里有色盲模式：形状放大，颜色改成蓝/橙/白。
- 顾客杯数只从固定集合出：**1、3、15、25、50、100、249、250、251、520**。没有数字的顾客只能是灰色`……`或红色奥客，不会出现“没数字却要收”的情况【改 C4】。

### 3.4 按错不罚

任何键都会播出完整的骂人演出和对应台词（见10.4三键矩阵），只是判定从“准”变成“偏”，加成变少。

### 3.5 长按蓄力三段

按下的那一刻锁定当前顾客，超时计时冻结（最多0.8秒），放开时出招。

| 段位 | 按住时长 | 倍率 | 手感 |
|---|---|---|---|
| 1段 · 轻骂 | < 0.20 s | ×1.0 | 轻震10ms，店员单手一挥 |
| 2段 · 重骂 | 0.20–0.50 s | ×1.5 | 中震25ms，拍柜台，震屏4px |
| 3段 · 狠骂 | 0.50–0.80 s | ×2.0 | 重震50ms，定格80ms，震屏10px，扩音器回授声 |
| 过蓄 | > 0.80 s | 自动以3段放出 | 不罚，店员憋到脸红自己爆出来 |

- 蓄力时店员逐段变脸：皱眉 → 青筋 → 站起来。按钮外圈三格进度环。
- 取舍：3段多花约0.5秒，“要快还是要狠”是一局里最基本的张力。

### 3.6 抢话（高手技巧）

- 顾客气泡里的字逐字打出，约0.6秒打完。打完前出手就是“抢话”。
- 抢话 + 准：排队额外 +1，火气 +1；**抢话打断红色奥客**额外火气 +3【改 C20】。
- 专属台词：“（打断）我没问你后面。”连续抢话5次得称号“抢话王”。
- 游戏里**没有任何奖励“等待”的机制**，等待只会拖慢节奏【改 C20】。

### 3.7 单局里的六个附加爽点（都不增加新按键）

| 名称 | 触发 | 效果 | 为什么不拖慢 |
|---|---|---|---|
| **保龄滚** | 3段“滚” | 顾客往后滑进队伍撞倒后面的人。被撞的人站起来喊“好凶！我也要被骂！”（录30种），每撞1人排队+1。撞倒上限由扩音器等级决定（3→5人），撞满5人出现“STRIKE!” | 动画在背景队伍层播放，下一位同时上前 |
| **团体框** | 3–5位同标记顾客挤在一起 | 柜台前出现一个框，2段以上一键处理全部，每人都算准，排队×1.5。“（一指扫过去）你、你、你，还有你，滚！” | 多人只花一次判定，每局2–3次 |
| **自动破功** | 离谱大单（例：全糖去冰珍珠椰果仙草布丁全加，520杯） | 玩家照常按收；店员**自动**嘴角失控一秒再板脸：“（咳）……刚刚没事。收！”排队+5 | 不需要额外操作【改：删除QTE】 |
| **复仇骂** | 服务腔之后的下一位用3段骂准 | 店员撕掉脸上的笑容，气势+8，排队+6，嘘声变欢呼 | 只是下一位的普通判定 |
| **前主管来电** | 每局1–2次，只在空档响起：开局前3秒、爆气结束后0.5秒、取餐日结束时【改 3.3】 | 2秒内往下滑挂断：“（挂掉）……谁啊。下一位！”火气+20，气势+5。不挂也没有惩罚。挂断次数跨局累计，最终Boss开场会念出来 | 不和判定抢拇指 |
| **拉铁门收摊** | 最后5秒 | 顶部垂下铁门拉环，往下拉或狂点：“今天卖完了！全部——两个月后再来！”按当时排队的10%加分（上限+300） | 取代最后5秒的顾客 |

- 超时−15。这是气势唯一的扣分来源。

### 4.7 打断预算（硬规则）【改 3.1】

| Boss阶段转场 | 0.8 s | 3 | 缩成0.4 s |
| 回头客愣住 | 0.5 s | 4 | 改成背景播放 |
| 名台词定格 | 0.25 s，同局第二次起不定格 | 5 | 不定格 |
| 排队升段演出 | **不冻结**，右上角小窗放大 | — | — |
| 组合标签、应援、保龄滚 | 不冻结 | — | — |

### 4.8 每天三星【改 C26、C27】

| 星 | 条件 |
|---|---|

### 4.9 数值预期（验算用）

## 6. 爆气

### 6.1 触发演出（1.0秒，不计入8秒）

1. 火气条闪红，BGM静音0.3秒，只剩心跳声。
2. 店员“啪”地放下号码牌，**一脚踩上柜台**，镜头从俯视切到仰视（顾客视角）0.4秒。
3. 大字砸下“**爆 气**”，柜台木头裂声，震屏14px。
4. BGM以+20 BPM切进爆气段落。

### 6.2 规则【改 C33】

| 项目 | 规则 |
|---|---|
| 时长 | **固定8秒**。只有麦克风能延长，最多+2秒。流派、工读生、每日挑战都不改时长 |
| 来客 | 每0.30秒自动上前一位，约26人 |
| 判定 | 不会超时，任何键都算准，播出那个键的骂法。乱按也很爽 |
| 加成 | 排队×2，连击照常累计，气势每人+1 |
| 台词 | 0.3–0.5秒的连珠炮：“滚！”“收！”“闭嘴！”“下一位！”“号码牌！”“两个月！”“黄金比例！” |
| 演出 | 被骂的人像保龄球瓶往后倒；每5下定格50ms |

### 6.3 可选麦克风（只检测音量）

- 首次开启说明：“只读音量大小，不录音、不上传、不辨识内容”。系统权限预设关闭。
- 本地计算RMS：超过−20 dBFS → 排队倍率×2.5；超过−10 dBFS → ×3，画面边缘出现扩音器音波。每持续大声1秒，爆气延长0.25秒，最多+2秒。
- 不开麦克风也能拿满×2。所有★2目标都不要求麦克风。
- 开启“小声模式”（18.3）时自动停用麦克风加成。

### 6.4 结束（三拍收尾）

店员喘气，慢慢坐回去，拉一下衣领，冷静地说“……下一位。”BGM回原速，火气归零，气势+10。战报记录“一口气骂了N个”。

## 10. 台词系统

### 10.1 九种骂法与比例

| 风格 | 目标比例 | 写法要点 | 例句 |
|---|---|---|---|
| 明骂 | 约10%（重拳） | X你妈公式，只用在最狠的时刻 | “少你妈！冰块加满才好喝！” |
| 嫌弃 | 13% | 翻白眼、看不上 | “（扶额）三个人共用一颗脑？滚。” |
| 冷静 | 13% | 不抬头、低温 | “以前那个已经离职了。几杯？” |
| 一本正经 | 13% | 服务话术的外壳 | “本店推荐：你离开。第二名：你快点离开。” |
| 真人反应 | 13% | 叹气、沉默、“蛤？”、动作 | “（沉默三秒）……蛤？” |
| 中二 | 约11%（每8–10位一次） | 突然燃、戏剧化 | “（俯视）从这里看……你们都好渺小。下一位！” |
| 算账 | 10% | 规则当场套回顾客 | “问价的加十块。（他张嘴）……又加十块。” |
| 250暗骂 | 9% | 复述250、不说破 | “251？（拿笔划掉一杯）250。收。” |
| 反差 | 8% | 凶店员破功一秒又恢复 | “（嘴角上扬一秒）……咳。收。两个月后来拿。” |

### 10.2 三条写作公式

| 公式 | 规则 | 例 |
|---|---|---|
| **X你妈** | 顾客原话里的**单字动词** + 你妈。顾客原话必须真的有那个字 | 顾客“可以**少**冰吗？”→“少你妈！冰块加满才好喝！”；顾客“绿茶……**改**红茶……再**改**奶茶”→“改你妈！再改，改去隔壁！”；顾客“我先**品**一下回甘”→“品你妈！你根本还没拿到！”；顾客“可以**拍**一张吗？”→“拍你妈！拍完排队，滚！” |
| **算账** | 一个荒谬单价 × 顾客自己说的杯数 → “自己算” | 顾客“50杯可以分开装吗？”→“一个袋子加十块，50杯，自己算！滚！” |
| **250暗骂** | 把250念得像在叫人 | “（停顿）好。二百五。……杯。号码牌拿好。” |

### 10.3 标杆台词（全作对照用）

共同点：**第一个词就转折**、**有一个具体动作或物件**、**最后两个字是凶的**。

| 台词 | 可以学的技巧 |
|---|---|
| “251？（拿笔划掉一杯）250。收。” | 暗骂不说出口，靠一个动作完成 |
| “（翻本子）250杯……找到了。（啪地合上）明天开始做。” | 把“现点现做 + 两个月”推到最荒谬的结论 |
| “（柜台电话响，接起来，低头看他）……我看到你了。（挂掉）滚。” | 用上高柜台俯视的构图 |
| “问价的加十块。（他张嘴）……又加十块。” | 规则当场套回顾客身上，第二拍靠顾客反应 |
| “急件一律两个月。特急件——（啪地盖章）三个月。” | 逻辑反转：越急越慢，盖章落在笑点 |
| “有。名称：下一位。密码：滚。”（问Wi-Fi） | 招牌台词塞进日常格式，适合做贴图 |
| “本店推荐：你离开。第二名：你快点离开。” | 服务话术外壳 + 三段递进 |
| “可以。加了就是另一杯。另一杯卖完了。”（加珍珠） | 服务腔→拒绝的微型三拍，不用粗口也很凶 |
| “一半？125？（摇头）你明明是完整的250。” | 假装夸人“完整”，其实骂得更重 |
| “少冰？冰块是来上班的，你要我裁员？” | 冰块拟人，连上主角被压榨的主线 |

### 10.6 语音切点：爆头 + 尾巴【改 M3】

顾客周期1.0–1.8秒，下一位最快0.15秒就上前，语音一定会重叠。所以每句拆两段：

| 段 | 长度 | 规则 | 例 |
|---|---|---|---|
| 爆头 | ≤0.6 s | 保证播完，承载笑点关键词 | “好。二百五。” |
| 尾巴 | 剩余 | 可被下一句截断，字幕停留0.8秒 | “……杯。号码牌拿好。” |

配音脚本用`|`标出切点。长句只当变体，只在爆气以外、气势80以上时播放。

| 1. 标记辨识 | 印60张顾客卡（灰/金/红 + 形状，含249裂痕），节拍器每1.5秒翻一张，测试者拍三张写着滚/闭嘴/收的卡 | 第3分钟起，一秒内正确率 ≥85%；249误判率 <30% 且测试者觉得“被骗很好笑” |
| 2. 三拍反差 | 一人扮店员，按测试者拍的卡大声念台词（用10.3标杆句和三键矩阵） | 每60秒至少笑出声3次；按错键时测试者仍然在笑（证明“按错不罚”成立） |
| 3. 服务腔 | 超时时扮店员的人必须用甜腻声念服务腔，其他人嘘 | 测试者主观评价“丢脸但想再来”≥4/5 |
| 4. 节奏 | 跑完一局90秒，记录爆气次数和打断时长 | 爆气约2次；打断总时长 ≤8秒 |
| 5. 数值 | 用纸本计分表手算排队公式 | 新手约90、熟练约250，和4.9一致 |
| 6. 数字原型 | 第3周做第1天前60秒可玩版 | 10位台湾玩家中 ≥7位在60秒内笑出声；≥6位主动要求“再一局” |

## 20. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 打断演出太多，节奏变碎 | 违背“快节奏、解压” | 4.7打断预算8秒硬上限；升段、组合、应援都不冻结 |
| 语音和顾客节奏重叠 | 听不清笑点 | 10.6爆头+尾巴切点；主台词≤14字 |
| 金/红色弱分不清 | 一秒判断失效 | 颜色+形状双编码；色盲模式 |
| 台词重复变烂 | 新鲜感下降 | 30位内不重复；原片台词只在双标记和第3天；稀有保底 |
| 配音成本失控 | 语音包×4市场 | 语音包只重录前80高频句 + 招牌台词；首发3派 |
| 250梗海外失效 | 港澳、英语市场不好笑 | 18.1立项前定案 |
| 原片IP纠纷 | 下架风险 | 18.4冻结复刻模式，台词与角色原创 |
| 分级与商店审核 | 上架被拒 | 学区店全成人；17+；“哔——”与小声模式；马新预设消音 |
| 红线回流（制作中又加回“不能骂的人”等） | 违背核心承诺 | 本文2.2红线表作为每次评审的检查表；配置中不允许“禁止按键”类字段 |
| 对某类人温柔的台词回流 | 违红线 | 所有破功由行为/事件触发，且最后一拍必须恢复凶，台词审核按10.3标杆检查 |
| 真实灾害与公关 | 负面舆论 | 台风只做“台风过后”固定档期，不联动警报 |
| 经济跑不通 | 升级太慢、玩家流失 | 15.2营业额公式验算，主线约覆盖60%升级总价 |
| 麦克风隐私疑虑 | 差评 | 只读音量、不录音不上传；预设关闭；不影响满分 |
