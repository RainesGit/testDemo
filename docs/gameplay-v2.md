# 《来250杯！》玩法 v2：解压、爽、关卡不单一

> 来源：2026-10-05 三位专家实机评审（手感与解压 / 核心循环与关卡 / 喜剧与玩家心理），用 Playwright 机器人实打第 1–7 天。
> 制作人方向：“画面不着急，先把玩法确定要好，解压，爽，好玩，非常重要！”“现在游戏关卡太过于单一。”“搞成沙威玛还能有解压的爽感吗？”
> 本文是玩法层面的最高依据：与 `first-minute-spec.md` 第 4.2、7 节或 `game-design.md` 冲突时，以本文为准；第 1 天开场剧本、三键与颜色不变。

## 0. 一句话

**沙威玛的爽是“我做得又快又好”，我们的爽是“我终于不用忍了”。**
借沙威玛的壳（一天一局、怪咖顾客、店铺成长），不借它的核（正确完成订单、时间压力、做错扣钱）。
核心改成：**每一下都骂得到人、骂得越早越狠越爽、玩家自己演完“正经 → 爆 → 秒恢复专业”三拍、每天一条新规则。**

## 2. 设计支柱（v2）

1. **任何时候按都有回应。** 没有死输入：顾客在飞时按 = 补刀；爆点后按 = “下一位。”
2. **每一键都是一句完整的骂。** 三键 = 三种态度：**滚** = 动作赶人，**闭嘴** = 打断嘴炮，**收** = 阴阳怪气地职业接单（第三拍本身）。按“偏”的键照样骂飞、照样好笑（偏键彩蛋），只是加成少。
3. **玩家亲手演三拍。** 按下 = 职业微笑（第一拍）；按住 = 憋；松手 = 爆（第二拍）；爆完再点 = “下一位～”（第三拍）。
4. **快 vs 狠，由玩家选。** 轻点 = 只播爆点，节奏快（连骂心流）；按住 = 铺垫 + 爆点 + 加大音量，分高、飞得远（细品笑点）。
5. **压力来自贪心，不来自惩罚。** 越早骂倍率越高（抢话 ×2）；慢只会“被迫营业”几秒，永远不提早打烊。
6. **每天一条新规则。** 每天的新东西必须改变“手在做什么”，不只是换台词。
7. **大演出稀缺化。** 快节奏里每 5 位一个完整三拍、250、Boss 才给大演出，笑点更响。

不变的硬规则（CLAUDE.md）：谁都能骂；骂“错”不罚（只少加成）；唯一的失败是太慢（被迫服务腔）；没有外送员、奇幻、身份梗；250 是招牌；三键与颜色不变；第 1 天开场剧本不变。

## 3. 一位顾客（1.5–3 秒）

```
看队伍里下一位的小牌子（预告）
→ 顾客探头举牌、开口（倍率条从 ×2 开始往下掉）
→ 玩家按下：店员瞬间职业微笑（计时冻结，最多 800 ms）
   ├─ 轻点（< 180 ms 松手）：只播爆点半句，顾客按所按键的方式飞走 ── 快
   └─ 按住再松手：铺垫 | 停顿 | 爆点（2 段 ×1.5，3 段 ×2，镜头推近、青筋、扩音器）── 狠
→ 顾客飞行中继续按 = 补刀（飞更远、震屏、前 2 下各 +1）
→ 爆点落地后 0.4 s 内再点 = “下一位～”（秒恢复专业，+1，下一位立刻上前）
```

| 规则 | 数字 |
|---|---|
| 速度倍率（准） | 抢话（顾客还在说）×2；t0 后 600 ms 内 ×1.5；1200 ms 内 ×1.2；之后 ×1 |
| 蓄力倍率 | < 180 ms ×1；180–800 ms ×1.5；≥ 800 ms 自动放出 ×2；台词永远不被切 |
| 准 | 排队 +⌈基础 × 速度 × 蓄力⌉，连击 +1，火气 + |
| 偏 | 照样骂飞，播所按键的偏键彩蛋台词，排队 +1，连击**冻结**（不清零不增长），火气不加 |
| 慢（超时） | 服务腔一句，连击清零；第 1 次免费，之后气势 −15；**气势归零 = 被迫营业 10 秒**（全部服务腔、排队 ×0.5），之后气势回 40 继续，**不打烊** |
| 补刀 | 前 2 下各 +1、火气 +2；之后只有反馈 |
| 收脸 | 爆点落地后 400 ms 窗口，任意键：+1，“变脸”连击 +1；不点没有损失 |
| 连击加成 | ⌊min(连击, 50) / 5⌋，最多 +10 |
| 大单 | 100 杯 +1、251 +2、520 +5、**250 +25**，大单全部 big 落地 |

## 4. 爆气：人潮冲柜台（重做）

- **火气靠本事挣**：抢话 +14、perfect +10、准 +6、补刀 +2；顾客出现不再加火气。满了以后店员发抖、柜台裂痕、三键发光，**玩家下一次按键触发**（“不忍了！”）。不按也不罚，条一直满着。
- **6 秒**：门外人潮冲进来，每 300 ms 冒出一个半个头举牌（不说话）。任意键把眼前这位按所按键的方式骂飞（+1）；颜色对 +2 加重击音。每位只能骂一次 → 速度上限 = 来客速度（约 20 人），不再奖励无限连点。
- 连珠炮**按键分组**并**点名本局遇过的奥客**：“少冰的！滚！”“要试喝的！闭嘴！”“问厕所的！收！两个月！”
- 收尾第三拍：停 0.5 秒，店员整理衣领：“……不好意思，刚刚失态了。下一位～”全场先静一拍再欢呼。
- 爆气连击单独计数，不并入普通连击。目标：爆气占全局分数 ≤ 30%。

## 5. 七天七条规则（每天一个“招式”）

每天 90 秒：热身 15 s → 当天招式第一次出现（≤ 1.5 s 引入，不弹说明页）→ 招式与普通顾客交替（中间一个 5–8 s 小事件）→ 最后 15 s 招式高潮 → 最后 5 s 拉铁门（狂按任意键）。

| 天 | 关卡 | 新招式（手在做什么） | 记忆点 |
|---|---|---|---|
| 1 | 开店（保留） | 开场原片剧本 + 三键 + 轻点/补刀/下一位 | “调你妈！黄金比例最好喝！” |
| 2 | 午休潮 | **来客预告 + 快嘴连骂**：看得到后面 2 位的小牌；连续准 5 位进入快嘴（只播爆点，每位约 1.6 s）；每第 5 位播完整三拍。超时与气势在此引入 | 一口气骂完一条队 |
| 3 | 原片日 | **两步顾客当主角**：原片 250 客出现 4–6 次（收 → 牌翻面 → 闭嘴）；**爆气**引入 | 全场合唱“黄金比例——最好喝！” |
| 4 | 250 凑单日 | **号码牌凑整**：按收把杯数累加，刚好 250 = 盖章大演出 +25 + 火气满；超过 = “两个月……喔，半年。”清零 +5。**蓄力憋骂**引入（蓄满收 = 杯数 ×2） | 第一个“打破颜色”的高手操作：故意收小单凑整 |
| 5 | 回嘴日 | **顾客回嘴、连环骂**：约 20% 顾客被骂后回一句，最多 3 层（+1/+2/+3），第 3 层一定回到职业腔；小事件“前主管来电”（滑掉电话） | “客诉也要排队。闭嘴。” |
| 6 | 晚八点人潮 | **团体框**（3–5 位同色挤在柜台，连打 N 下，最后一下全飞，排队 ×1.5）+ **改单客**（牌子在说话时换色：抢不抢？）+ 249 陷阱 | 一指扫过去：“你、你、你——收！” |
| 7 | Boss：前主管来排队 | **五步 Boss**：点单 → 调甜 → 要统编 → 砍价 520→250（乐句式连按）→ “你还记得我吗？”憋满放开 | “记得。你是二百五号。两个月后来拿。下一位！” |
| 8+ | 不打烊（无尽）+ 每日挑战 | 每 30 s 换时段，轮换第 2–6 天的招式；每日固定种子 + 星期主题（周二“二百五日”只出 249/250/251） | 排行、和朋友比同一天 |

**小事件**（每局最多 1–2 个，只用三键，不冻结判定）：大声公路过（5 s 狂按，每下 +1，上限 +20）、全场应援（连击 ≥ 30，跟节拍按收）、前主管来电（按两下挂断）、计算机老虎机（按住收，停在 250 = JACKPOT +25：“刚好二百五。跟你一样。”）、盖章连打（8 s 狂点收）、两个月后取餐日（之前收过的大单客回来取，连打金牌）。

## 6. 回访：星、评级、图鉴

- ★1 排队门槛（爆气修正后重算）、★2 当天招式目标、★3 小黑板谜语（例：“他还没嗯完。”→ 抢话滚犹豫客）。
- 结算评级 C / B / A / S / **250**（S 且排队尾数刚好 250 时出金色“250”评级）。保存每天最高排队与星数，显示“新纪录！”“距离 ★3 还差 …”。
- **今日最佳一骂**改按“玩家怎么骂”选：憋满放开 > 回嘴第三层 > 第一次偏键彩蛋 > 收脸 > 250 jackpot。分享卡用台湾口吻：“服务态度 ★☆☆☆☆　排队 ★★★★★”。
- **骂人图鉴**：每位顾客 3 格（滚 / 闭嘴 / 收），第一次听到闪 NEW；集满一类解锁“笑点型升级”（号码牌取餐时间：两个月 → 一季 → 半年 → 明年今天 → 退休那天）。升级让骂人更夸张，不让做奶茶更快。

## 7. 不做的（避免变成上班）

- 不做配料、组装、做对订单；不做做错扣钱；不做提早打烊的悬崖；不做“憋住不骂”的关卡；不做骂错的惩罚。

验收指标（机器人）：输入死时间 < 10%（现约 70%）；普通玩家每 10 s 有反馈的按键 ≥ 6（现约 3）；普通玩家 90 s 服务 ≥ 35 人（现 16）；爆气占分 ≤ 30%（现 70–99%）；乱按到不了 ★1（现在全过）；高手 / 普通差距 1.5–2 倍（现约 10 倍）；新手不会提早打烊。

### 8.1 阶段一：已完成（2026-10-05）

已在网页原型实现（`game/src/engine.js`、`main.js`、`ui.js`、`days.js`），没有改台词，不需要重建语音。验收用 `game/tools/bots.mjs`（四个机器人：熟手 / 普通 / 手残 / 乱按，第 1–7 天，种子 1–3，共 84 局，实时游玩）。

**做了什么**
- 补刀：顾客在飞时（出手到爆点结束 + 200 ms）按 = 补刀，飞远 40%（滚多转 180°）、震屏 4 px / 80 ms、定格 30 ms、合成拍桌声、S4 小花字（所按键的字）；**按对之后**前 2 下各 +1、火气 +2，之后只有反馈；不出店员语音，不切台词。
- 叫号：之后第一下 = “下一位。”（复用 `SYSTEM.next` 里“（不抬头）下一位。”的语音），下一位立刻上前（台词一定先说完）。顾客可以在“下一位。”的尾巴开口。离可答还差 ≤ 150 ms 的按键先存起来，到时生效。
- 速度倍率：抢话 ×2、t0 后 < 600 ms ×1.5、< 1200 ms ×1.2，乘在“1 + 连击加成”上并向上取整；牌角显示 ×2 / ×1.5 / ×1.2。
- 偏键：+1，连击冻结，火气不加；顾客照样按所按键的方式在爆点飞走，正确键的提示闪烁放到台词之后（下一张牌等它闪完）。
- 爆气：火气靠本事（抢话 +14、perfect +10、准 +6、补刀 +2，来客 0）；满了条发光、三键脉动、店员发抖，**下一次按键**触发；柜台前的顾客先让开，爆气后第一个回来。6 秒，每 300 ms 冒一个不说话的半个头，按任意键骂飞（+1），颜色对 +2 加重击；每头一次。连珠炮按所按键分组（`rageLines` 10 滚 / 10 闭嘴 / 10 收 / 6 通用）。爆气连击单独计数。收尾：静 0.5 秒，店员用服务腔说“（叹气）……下一位。”。
- 超时：第 1 次免费，之后气势 −15（起始 70，准 +2，perfect +4）；气势 0 = 被迫营业 10 秒（全部服务腔，排队 ×0.5 向上取整），之后气势回 40。**删除了提早打烊**，只按时间收店。
- 蓄力 2 段不再插入随机喊叫，顾客自己的爆点用 mega 完整播完。
- 大单：100 杯 +1、251 +2、520 +5、250 杯 +25，全部 big 落地。连击加成封顶 ⌊min(连击, 50)/5⌋。

**为了验收指标做的调整（与本文第 3–4 节的差异）**
- 抢话必须是“顾客在说话”：牌子举好（`cutInFromMs` = 入场 + 280 ms）之前的按键算“抢跑”，×1、不算 perfect、没有大单加成（照样 big 落地）。否则乱按的人每次都是 ×2 抢话，分数和普通玩家一样。
- 偏键之后的补刀只有反馈（不加排队、不加火气），和偏键本身一致。
- 蓄力加成改为平加 +1 / +2（原 +1 / +3，阶段三重做蓄力），而且第 4 天介绍蓄力之前不加分。
- 第 3 天前 30 秒火气 ×2（普通玩家第一次爆气约在 25–30 秒）。
- ★1 重算：第 1–6 天 30 / 80 / 105 / 100 / 115 / 120（第 7 天仍是 Boss 日，无门槛）。

**还没达标、留给后续阶段**
