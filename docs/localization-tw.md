# 台湾用语本地化（zh-TW 显示）

《来250杯！》第一市场是台湾。繁体版本只改**显示**：`game/src/hant.js` 的 `toHant()` 在 zh-TW / zh-HK / zh-MO
浏览器（或 `?lang=zh-TW`）里把画面上的每个文字节点转成繁体。简体原文、语音 clip 的 key、引擎都不变，
所以本文件只列显示映射；语音的改写建议见第 5 节，`content.*.js` 不改（语音包按原文建索引）。

## 1. 审查范围与结论

逐条看过画面上会出现的全部中文：`content.zh.js`（100 位顾客的 says / reply / alt，SYSTEM 的 next、polite、boo、
rageStart、rageLines、milestones、closing、ui、start、opening 全部子项、originalCustomer、tips、unlock、daySlow），
`art.js`（灯箱、取餐号码、匾额、门口监视器标签、新闻跑马灯、取餐票），`ui.js`（开店卡、打烊卡、战报、DECOR、
DEFAULT_UI），`main.js` 的后备文字，`index.html`（title、noscript）。`days.js` 的分类名、顾客 `name` / `cat`
不上画面，不处理。

结论：台词（lines-zh v3、voice-script-zh）本来就是按台湾口语写的——喔、啦、齁、蛤、欸，网路、外带、载具、
统编、捷运、骑楼、计算机（=计算器）、冷气、浏海、直播主、聊天室、奥客、三十七趴、起跳、质感、打卡、空拍、
爆气、中药行、重修都已经是台湾说法。真正读起来像大陆的只有少数几个词，外加几个字形问题，所以映射表很短；
没有为了“看起来有改”而硬改。

引号单独处理。结果幂等（DOM 观察器会重读自己写过的文字）；测试逐条检查。

## 3. 实现与测试

- `game/src/hant.js`：`PHRASES`（字形）、`TW_PHRASES`（用语）、`TW_WHOLE`（整段）、`TW_PUNCT`（引号）。
  词表合并成一个正则，最长键优先（所以“倒喝采”先于“喝采”）。值里不能含任何键，也不能含字表还会再转的字。
- `game/test/hant.test.mjs`：每个映射的实际台词断言；会误伤的短词各有反例（迎接客人、这个赞助、杆子、这边念头、
  怨念、英文引号）；招牌台词不变；每个值再转一次不变；每个键都确实出现在画面文字里（无死条目，干杯 / 饼干 除外）。
- 新增台词时：如果用到第 2.1 节左栏的词会自动转换；如果出现新的大陆用语，加到 `TW_PHRASES` 并补测试。
  只上画面的文字（舞台指示、花字、UI）随时可以加；会念出来的词还要看第 5 节。

## 4. 港澳

港澳目前也走同一个 `toHant()`。表里只有“铜板”是台湾专用（港澳读来别扭）；客诉、铁卷门在香港不是首选但看得懂；
大声公、惊见、喝倒彩、接待、讚、「」两地通用。更大的差异其实在台词本身：捷运、骑楼、载具、统编、网路、齁、三十七趴
都是台湾词，字表（裡 vs 港式 裏）也是台湾字形。所以没有单独做港澳表——港澳版需要的是一次台词改写，而不是多几条映射。
到时候可以把 `TW_PHRASES` 拆成 `{ tw, hk }` 两列，由 `main.js` 的语言标签传入地区。

## 5. 语音：建议台湾版重录或改写的台词

语音包由简体原文生成（Kokoro-82M，普通话 G2P，大陆口音）。显示改了而语音没改的地方，字幕和声音会差一个词。
以下只是建议，**本次没有改 `content.*.js`**（改原文就要重建语音包，见 `game/tools/voice/README.md`）。

### 5.1 用词（字幕与语音不一致）

| 顾客 | 台词（原文） | 建议台湾说法 | 备注 |
|---|---|---|---|
| #88 要投诉 | 我要投诉你喔！ / （递号码牌）投诉？排队。你第二百五号。 / 拿好。投诉结果，两个月后来拿。 | 客诉 | 唯一一个会被念出来、而显示已改的词 |
| #70 要收据 | 250杯，收据要给我喔。 / 收据。满意了？ / 收据！载具！取餐证！全在这一张！！ | 可考虑“发票”（并把 alt 改成“发票！载具！统编！”） | 台湾饮料店更常听到发票；属于改写，不是必须 |
| 开场 c3c / 原片顾客 | 少甜少冰！ | 少糖少冰 | 原片台词，按 spec 不动；若出台湾配音版可讨论 |

舞台指示里的词（硬币、扩音器、铁门、倒喝采、引号内文字）不朗读，只改显示就够了。

### 5.3 整体口音

Kokoro 的中文声线是大陆普通话（儿化、卷舌、轻声都偏北方）。台湾正式版最理想是换台湾口音的声线或真人配音，
同时处理 5.1 / 5.2；在那之前，以上几处是最容易被台湾玩家听出来的地方。
