# 台湾繁体写作指南（zh 原文）

制作人指示（2026-10-08）：“只支持繁体中文和英文，别搞简体，不会上中国大陆”。所以《來250杯！》的中文**原文就是
台湾繁体**：`game/src/content.zh.js`、`src/*.js` 里的全部中文字符串（DECOR、DEFAULT_UI、GESTURE_TEXT、VOICE_TEXT、
花字、事件面板……）、`art.js` 的 SVG 文字（匾额「現點現做」、灯箱「翡翠檸檬 / 黃金比例 不能調」、叫号器「取餐號碼」、
门口监视器「門口 / 騎樓 / 捷運出口 / 新聞快報」、取餐票）、`index.html`。没有简体版本，也没有运行时转换
（原来的 `src/hant.js` 已删除）。任何 `zh*` 浏览器（包括 zh-CN）都显示繁体中文，其余语言显示英文；`?lang=zh` / `?lang=en`
可强制。港澳马新目前用同一份台湾文字。

本文件原来是“简体原文 → 台湾显示”的映射表，现在是**写新台词时的用字用词指南**。设计文档（game-design.md、
gameplay-v2.md、lines-*.md、voice-script-zh.md 等）是内部文件，仍是简体；把其中的台词搬进游戏时必须按本指南写成台湾繁体。

## 1. 检查

- `node tools/check-content.mjs` 的 **T1**：`src/*.js`、`index.html`、`style.css` 和全部内容里不能出现任何简体专用字或
  非台湾字形（`game/tools/hans-chars.mjs`，由 `tools/gen-hans-chars.py` 从 OpenCC 的 STCharacters / TWVariants 生成：
  一个字只要 OpenCC 把它转成别的字、而候选里没有它自己，就算简体专用；裏 → 裡、着 → 著 这类非台湾字形也算），另外
  `后 / 干 / 里` 虽然是合法繁体字，但在本作里只会是漏转（後、乾 / 幹、裡），也一律报错；真的要用（皇后、公里）就加进
  `T1_ALLOW`。
- `node tools/check-hant.mjs <url>`：用 zh-CN 浏览器跑开场和第 1 天、再跑第 3–7 天，记录画面上出现过的每一段文字
  （文字节点、SVG、aria-label / title、document.title），出现简体字就失败。
- 新台词的写法：先写简体草稿也可以，用 OpenCC `s2twp` 转（`pip install opencc-python-reimplemented`），再按下面第 2–3 节
  逐字看一遍。不要用 `s2twp` 的词汇替换不看就收：它会把“菜单”改成“選單”（电脑选单）、“递回手机”改成“遞迴手機”、
  “挂断”改成“結束通話”，这三处在转换时已手工改回。

## 4. 港澳

港澳目前用同一份台湾文字。只有“銅板”是台湾专用（港澳读来别扭）；客訴、鐵捲門在香港不是首选但看得懂；大聲公、驚見、
喝倒彩、接待、讚、「」两地通用。更大的差异在台词本身：捷運、騎樓、載具、統編、網路、齁、三十七趴都是台湾词，字形也是
台湾字形（裡 vs 港式 裏）。港澳版需要的是一次台词改写，到时再加一份 `content.zhHK.js` 之类的覆盖层。

## 5. 语音

语音包（Kokoro-82M）的 key 由**繁体原文**算出；`tools/voice/build_voice.py` 只在送进 misaki G2P 之前用 OpenCC `t2s`
把文字转成简体（再把 著 → 着），因为 misaki 按简体训练。转回来的文字和旧简体原文逐句一致（只有 #88 的 投訴 → 客訴），
所以读音质量不变。声线仍是大陆普通话。

### 5.1 用词（字幕与语音）

| 顾客 | 台词 | 备注 |
|---|---|---|
| #88 要客訴 | 我要客訴你喔！ / 客訴？排隊。你第二百五號。 / 拿好。客訴結果，兩個月後來拿。 | 已改词，语音已按“客诉”重新生成 |
| #70 要收據 | 250杯，收據要給我喔。 | 台湾饮料店更常听到“發票”；属于改写，不是必须 |
| 开场 c3c / 原片顾客 | 少甜少冰！ | 台湾店员会说“少糖少冰”；原片台词，按 spec 不动 |

### 5.2 读音（同字不同音，Kokoro 会读成大陆音）

| 字 / 词 | 大陆读音 | 台湾读音 | 出现的朗读台词 |
|---|---|---|---|
| 微（微冰、微糖） | wēi | wéi | #14 says「微冰就好，謝謝喔～」、reply / alt 的「微冰」 |
| 質（質感） | zhì | zhí | #81 says「要質感，又要便宜喔」、alt「質感，就是排隊」 |
| 誰 | shuí / shéi | shéi | #67 reply「誰付錢誰留下」 |
| 蛤（疑问语气） | 可能读成 gé（蛤蜊） | há | #5、#7、#18、#53、#62 |
| 齁（语尾） | hōu | 台湾口语近 honnh / hioh | #2、#6、#15、#57、#68 |
| 二百五 | èr bǎi wǔ | 台湾数数说“兩百五” | 二百五当骂人的梗是大陆说法；作为招牌保留；#41、#49 等数字场合原文已用“兩百五十” |

### 5.3 整体口音

Kokoro 的中文声线是大陆普通话（儿化、卷舌、轻声都偏北方）。台湾正式版最理想是换台湾口音的声线或真人配音，
同时处理 5.1 / 5.2；在那之前，以上几处是最容易被台湾玩家听出来的地方。
