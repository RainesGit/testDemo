## 使用说明

### 1. 标注规范（引自 `voice-bible.md` 第3节，本稿补充的条目已标“定稿补充”）

| 符号 | 含义 | 执行 |
|---|---|---|
| ／ | 短停 | 0.2–0.3s |
| ／／ | 长停 | 0.6–1.0s，让沉默本身变成笑点。**动作括号后面不再加 ／／**，动作静音由引擎处理 |
| （气口） | 定稿补充 | 约0.1s 的换气，不算停顿 |
| **粗体** | 重音 | 音量和音高同时加重 |
| ｜ | 切点 | 前面是“爆头”，≤0.6s，一定播完；后面是“尾巴”，可被截断 |
| ⇢ | 从爆骂切回正经 | 截断 → ≤0.15s 换气 → 降到 L1。**⇢后像念公告，音量降两级，不能带笑，也不能变甜** |
| ⤴ | 从破功恢复凶 | 同上，但切到 L3 |
| —— | 定稿补充：**只表示拖音** | 拖音一律放在 ｜ 之后；断开一律用 ／ |
| …… | 定稿补充：**无声迟疑**（不出气） | 约0.3–0.4s；不放在爆头里 |
| 软 | 定稿补充 | 音量和强度维持原级，音色放暖、带气音，**≤1.0s** |
| [哔:…] | 后期消音范围 | 演员照念原音；只盖“你妈”两字，动词照常播放 |
| （） | 动作或情境 | 不念；有声音时写“出声”；“笑”的动作一律注明“无声”或“僵硬”，避免和服务腔混淆 |
| 〔SFX:…〕 | 音效组提供 | 演员留空档 |
| 〈n.ns〉 | 目标时长 | 从第一个音到最后一个音，不含动作静音；容差 ±10% |
| L1–L5 | 强度 | L1冰点 / L2不耐烦 / L3标准凶（本稿：压着喉咙，不吼）/ L4拍桌 / L5炸裂 |
| 快 / 常 / 慢 | 语速 | 估时按 快≈6.5字/秒、常≈5字/秒、慢≈4字/秒 |

### 2. “250”念法（P0，全稿通用）

- **顾客**一律念“两百五十（一）杯”，这是台湾的正常读法。
- **店员**在暗骂句里念“**二百五**”。从“两”换成“二”就是骂人，念得像在叫一个人的名字。
- 店员台词里的数字一律写成汉字，照字念。顾客栏的阿拉伯数字是气泡文字，A级顾客照“两百五十”的读法录。
- #50 店员念“**五二零**”（告白谐音），顾客念“五百二十杯”。

### 3. 全稿禁令

- 店员**禁止说“您好”和“您”**。这两个词只留给失败时的服务腔。
- 主台词明骂（X你妈）共7句；每50句里“隔壁”“自己算”“跟你很配／跟你一样”各不超过2次。

### 4. 表格说明

- 编号栏写“序号 / ID + 风格·按键”，★＝标杆句。
- 顾客栏写“名字 + 原型声线·配音级别”。A＝全配音；B＝语气音加气泡；C＝无人声。
- 变体格式：〔风格〕台词 L级 语速〈时长〉。
- 强度栏写变化过程；统计时按**峰值**计（例：L1→L4 计 L4；L1⤴L3 计 L3；L5⇢L1 计 L5）。
- 录音时每句录“标准”和“压缩”两个 take，压缩版作保险，不超过2.5s（P2）。
- 一句里有 ⇢ 或 ⤴ 的，整句一次录完，禁止拼接。
